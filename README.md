# Portfolio Website 

## Description
A responsive portfolio website developed to showcase my skills, education, projects and experience as a Computer Science and Artificial Intelligence student.
The website was created using HTML, PHP, CSS, JavaScript and MySQL. It has a portfolio section and a blog system with user login and database functionality.

## Features
-Responsive portfolio website.
-About Me section.
-Education and experience sections.
-Skills and projects showcase.
-User login system. 
-Blog functionality. 
-Add and delete blog posts. 
-Database integration. 
-Responsive design for desktop, tablet and mobile devices. 

## Technologies Used 
-HTML
-PHP
-CSS
-JavaScript
-MySQL

## How to Run 
1. Install XAMPP.
2. clone this repository.
3. Move the project folder into the XAMPP 'htdocs' directory.
4. Start Apache and MySQL in XAMPP.
5. Import the required database into phpMyAdmin.
6. Open the project in your browser.
